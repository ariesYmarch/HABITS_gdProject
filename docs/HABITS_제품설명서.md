# HABITS 제품 설명서

## 1. 서비스 소개

HABITS는 자신의 성향과 감정 패턴을 바탕으로 개인에게 맞는 습관을 제안하고, 꾸준한 이행을 돕는 AI 기반 습관 코칭 모바일 애플리케이션입니다. 단순한 체크리스트 앱을 넘어, 사용자가 작성한 감정 일기와 습관 이행 데이터를 교차 분석하여 주간·월간 피드백 리포트를 제공합니다. 이를 통해 사용자는 자신이 어떤 상황에서 습관을 잘 이어가는지, 또는 무너지는지를 객관적으로 파악하고 지속적인 자기 성장을 이어나갈 수 있습니다.

본 서비스는 치료나 심리 상담을 목적으로 하지 않으며, 일상적인 자기 성찰과 성장을 지원하는 도구로 설계되었습니다.

### AI 기술 구성

HABITS는 두 가지 AI 기술을 조합하여 개인화된 경험을 제공합니다.

첫째, **KoELECTRA 기반 감정 분석 모델**을 사용합니다. 사용자가 작성한 감정 일기 텍스트를 입력받아 기쁨, 평온, 뿌듯, 희망, 슬픔, 짜증, 불안, 피로의 8가지 감정 클래스로 분류합니다. 한국어 감성 대화 말뭉치로 파인튜닝된 모델의 분석 결과와 한국어 감정 키워드 사전을 7:3 비율로 결합하여 최종 감정 분포를 산출합니다.

둘째, **Google Gemini 2.5 Flash**를 사용합니다. 사용자의 성격 유형, 이상적 자아, 생활 방식, 주간 일정을 입력받아 습관 후보 목록 중 사용자에게 가장 적합한 습관을 선정하고 최적의 시간대를 배정합니다. 또한 누적된 이행 데이터와 감정 데이터를 바탕으로 리포트의 분석 문단과 추천 이유를 자연어로 생성합니다.

## 2. 시작: 회원가입 및 온보딩

### 2.1 회원가입

애플리케이션을 처음 실행하면 환영 화면이 나타납니다. 아래 절차에 따라 계정을 생성합니다.

1. 환영 화면에서 '계정 만들기' 버튼을 선택합니다.
2. 이메일 주소를 입력합니다.
3. 비밀번호를 입력합니다. 비밀번호는 영문과 숫자를 포함하여 8자 이상으로 설정해야 합니다.
4. 닉네임을 입력합니다.
5. '가입하기' 버튼을 선택하면 계정이 생성되고 온보딩 화면으로 이동합니다.

[그림 1. 회원가입 화면]  
① 이메일 입력 필드 ② 비밀번호 입력 필드 ③ 닉네임 입력 필드 ④ 가입하기 버튼

### 2.2 로그인

이미 계정이 있는 경우 아래 절차에 따라 로그인합니다.

1. 시작 화면에서 '로그인' 버튼을 선택합니다.
2. 가입 시 사용한 이메일 주소와 비밀번호를 입력합니다.
3. '로그인' 버튼을 선택합니다.

비밀번호를 잊어버린 경우 로그인 화면 하단의 '비밀번호를 잊으셨나요?' 항목을 선택합니다. 가입 시 사용한 이메일 주소를 입력하면 비밀번호 재설정 링크가 발송됩니다.

### 2.3 온보딩: 나를 파악하는 10단계

최초 로그인 후에는 서비스 이용을 위한 온보딩 과정이 진행됩니다. 온보딩은 총 10단계로 구성되며, 이 과정에서 수집된 정보를 바탕으로 사용자에게 맞춤형 습관이 추천됩니다.

**1단계: 이름 입력**  
서비스 내에서 사용할 닉네임을 입력합니다.

**2단계: 서비스 안내**  
HABITS가 어떤 방식으로 동작하는지 간략히 안내합니다.

**3~4단계: 성격 유형 테스트**  
36개의 성격 해시태그를 제시하며, 현재 자신의 모습에 해당하는 태그를 선택합니다. 선택 결과를 바탕으로 '현재의 나'에 해당하는 성격 유형이 도출됩니다.

**5~6단계: 이상적 자아 탐색**  
앞서 진행한 테스트와 동일한 방식으로 '이상적인 나'에 해당하는 성격 유형을 선택합니다. 이 선택은 이후 습관 추천의 방향성이 됩니다.

[그림 2. 성격 유형 테스트 화면]  
① 해시태그 선택 영역 ② 선택된 태그 표시 ③ 다음 단계 버튼

**7단계: 생활 방식 입력**  
현재 직업 또는 주된 생활 방식을 선택합니다.

**8단계: 일주일 일정 입력**  
7일간의 일정을 타임테이블 형태로 입력합니다. 수면, 출퇴근, 업무·학업, 식사 등의 시간대를 표시하면 AI가 사용자의 여유 시간대를 파악하여 습관 시간 배정에 활용합니다.

[그림 3. 타임테이블 입력 화면]  
① 요일 행 ② 시간대 열 ③ 블록 유형 선택 영역

**9단계: AI 맞춤 습관 추천 및 선택**  
Gemini 2.5 Flash가 성격 테스트 결과, 이상적 자아 유형, 생활 방식, 주간 일정을 종합하여 사용자에게 적합한 습관 후보를 선정하고 각 습관에 최적의 시간대를 배정합니다. 목록에서 실천하고 싶은 습관을 선택하면 해당 설정이 홈 화면에 등록됩니다.

**10단계: 온보딩 완료**  
선택한 습관이 확정되고 홈 화면으로 이동합니다.

## 3. 홈 화면: 오늘의 습관 관리

홈 화면은 선택한 날짜의 습관 목록과 이행 현황을 보여줍니다.

[그림 4. 홈 화면]  
① 주간 캘린더 (날짜 선택) ② 오늘의 습관 목록 ③ 완료 상태 표시 ④ 습관 추가 버튼 ⑤ 하단 내비게이션 바

### 3.1 날짜 이동

화면 상단의 주간 캘린더에서 날짜를 선택하면 해당 날의 습관 목록이 표시됩니다. 왼쪽 상단의 화살표를 선택하면 이전 주 또는 이전 달로 이동할 수 있으며, 과거 날짜와 미래 날짜 모두 습관 체크가 가능합니다.

### 3.2 습관 체크

각 습관 항목 우측의 버튼을 사용하여 이행 여부를 기록합니다.

- 오늘 날짜의 미완료 습관에는 재생 버튼이 표시됩니다. 재생 버튼을 선택하면 타이머 화면으로 진입하며, 타이머가 완료되면 해당 습관이 자동으로 완료 처리됩니다.
- 과거 또는 미래 날짜의 미완료 습관은 원형 버튼을 선택하여 바로 완료 처리할 수 있습니다.
- 완료된 습관의 체크 표시를 다시 선택하면 완료가 취소됩니다.
- 각 습관 항목을 오른쪽으로 스와이프해도 완료 여부를 전환할 수 있습니다.

### 3.3 습관 추가

1. 홈 화면 하단의 '+' 버튼을 선택합니다.
2. 직접 습관 이름을 입력하거나 추천 템플릿 목록에서 선택합니다.
3. 빈도, 시간대, 소요 시간을 설정합니다.
4. '추가' 버튼을 선택하면 습관이 등록됩니다.

### 3.4 습관 수정 및 삭제

홈 화면의 습관 목록에서 수정하고 싶은 습관 항목을 길게 누르면 수정 및 삭제 메뉴가 나타납니다.

## 4. 감정 일기 작성

하단 내비게이션 바의 일기 아이콘을 선택하면 오늘의 감정 일기 화면으로 이동합니다.

[그림 5. 감정 일기 작성 화면]  
① 기분 점수 슬라이더 ② 감정 태그 선택 영역 ③ 일기 텍스트 입력 영역 ④ 저장 버튼

### 4.1 작성 방법

감정 일기는 세 가지 방식으로 오늘의 상태를 기록합니다.

1. **기분 점수 입력**: 화면 상단의 슬라이더를 좌우로 이동하여 오늘의 전반적인 기분 점수를 입력합니다.
2. **감정 태그 선택**: 기쁨, 평온, 뿌듯, 희망, 슬픔, 짜증, 불안, 피로 중 오늘의 감정에 해당하는 태그를 하나 이상 선택합니다.
3. **일기 텍스트 작성**: 텍스트 영역에 오늘 있었던 일이나 감정을 자유롭게 작성합니다. 작성된 텍스트는 KoELECTRA 기반 감정 분석 모델을 통해 분석되며, 이 결과가 AI 리포트 생성에 반영됩니다.

작성이 완료되면 '저장' 버튼을 선택합니다. 같은 날 일기 화면에 재진입하면 기존 내용을 불러와 수정할 수 있습니다.

## 5. 피드백 보기: 나의 트렌드 확인

하단 내비게이션 바의 피드백 아이콘을 선택하면 기간별 습관 및 감정 트렌드를 확인할 수 있습니다.

[그림 6. 피드백 화면 — 진행 탭]  
① 기간 선택 탭 ② 전체 이행률 원형 그래프 ③ 습관별 이행률 막대 그래프 ④ 해시태그별 이행률

### 5.1 기간 선택

화면 상단에서 주간, 월간, 올해 중 원하는 기간을 선택합니다. 좌우 화살표를 선택하여 이전 기간으로 이동할 수 있습니다. '올해' 탭은 올해 1월 1일부터 오늘까지의 전체 집계를 보여줍니다.

### 5.2 진행 탭

선택한 기간의 전체 습관 이행률을 원형 그래프로 표시합니다. 아래로 스크롤하면 습관별 개별 이행률과 성격 테스트에서 선택한 해시태그별 이행률 막대 그래프를 확인할 수 있습니다. 이를 통해 어떤 성향을 강화하는 습관을 얼마나 잘 이어갔는지 파악할 수 있습니다.

### 5.3 감정 탭

선택한 기간 동안의 평균 감정 점수와 감정 유형별 분포 비율을 확인합니다. 각 날짜의 기분 점수가 선 그래프로 표시되어 감정의 흐름을 한눈에 파악할 수 있습니다.

### 5.4 일기 탭

해당 기간에 작성된 일기 목록을 날짜 역순으로 보여줍니다. 삭제하고 싶은 일기 항목 우측의 삭제 버튼을 선택하여 일기를 삭제할 수 있습니다. 삭제된 일기는 이후 생성되는 리포트 분석에서 제외됩니다.

## 6. AI 리포트: 나의 변화 읽기

하단 내비게이션 바의 리포트 아이콘을 선택하면 AI가 생성한 피드백 리포트를 확인할 수 있습니다.

[그림 7. AI 리포트 화면]  
① 리포트 생성 버튼 ② 주간/월간 탭 전환 ③ 리포트 카드 목록 ④ 졸업 후보 알림 카드

### 6.1 리포트 생성 방식

HABITS의 AI 리포트는 결정적 진단과 언어 모델 풍부화를 결합한 방식으로 생성됩니다.

먼저, 해당 기간의 습관 이행률을 5구간으로, 감정 극성을 4구간으로 분류하여 총 20가지 진단 패턴 중 사용자에게 해당하는 진단을 결정합니다. 이행률 구간과 감정 구간의 조합마다 진단 라벨과 분석 문단이 사전 정의되어 있어 AI 환각 위험 없이 일관된 진단이 제공됩니다. 이후 Gemini 2.5 Flash가 사용자의 실제 데이터를 인용하여 분석 문단을 개인화하고, 이전 리포트가 2개 이상 누적된 경우 시계열 패턴 인사이트를 추가합니다.

습관 졸업 판정 기준은 4주 연속 이행률 90% 이상, 긍정 감정 비율 50% 이상입니다. 이 기준은 심리학적 습관 형성 연구에서 제시하는 자동화 임계값을 참고하여 설정하였습니다.

### 6.2 리포트 생성 시점

리포트는 두 가지 방식으로 생성됩니다.

- 주간 리포트: 매주 일요일 오후 10시에 자동으로 생성됩니다.
- 월간 리포트: 매월 말일 오후 10시에 자동으로 생성됩니다.

자동 생성 이전에도 리포트 화면 상단의 '리포트 생성' 버튼을 선택하여 즉시 생성할 수 있습니다. 동일한 기간에 리포트가 이미 존재하는 경우 먼저 삭제한 후 재생성해야 합니다.

### 6.3 리포트 구성

생성된 리포트 카드를 선택하면 상세 내용을 확인할 수 있습니다.

**종합 진단**  
해당 기간의 습관 이행률과 감정 분포를 조합하여 진단 라벨과 설명 문단이 제시됩니다.

> 예시  
> "성취도도 높고 마음도 가벼웠던 기간이었어요."  
> "이행률이 80%를 넘겼고, 긍정 감정이 우세하게 나타난 안정적인 한 주였습니다. 현재의 루틴이 부담 없이 자리를 잡아가고 있다는 신호예요."

**분석 줄글**  
행동 패턴, 감정 흐름, 이행률과 감정 간의 상관관계, 감정 변동성 등을 자연어로 설명합니다. 리포트가 2개 이상 누적된 경우 이전 기간과 비교한 시계열 패턴 인사이트가 추가됩니다.

> 예시  
> "이번 주 기분이 좋았던 날에는 '아침 스트레칭' 이행률이 90%였지만, 감정이 무거웠던 날에는 40%로 낮아지는 패턴이 관찰됩니다. 컨디션의 영향을 크게 받는 습관으로 보입니다."

**추천 액션**  
진단 결과에 따라 실행 가능한 액션이 제시됩니다.

- 이행률이 낮은 경우 '빈도 축소' 버튼이 나타납니다. 선택하면 가장 이행률이 낮은 습관의 빈도와 시간대를 직접 조정할 수 있는 화면이 열립니다.
- 이행률은 높지만 감정이 지쳐있는 경우 '어떻게 도와드릴까요?' 선택 화면이 나타납니다. '휴식 습관 추가하기' 또는 '이 습관을 다른 습관으로 변경' 중 하나를 선택하여 진행합니다.

[그림 8. 추천 액션 화면]  
① 추천 카드 ② 빈도 축소 또는 휴식 개입 선택 버튼 ③ 졸업 후보 알림

**졸업 후보 알림**  
4주 연속 90% 이상 이행하고 긍정 감정 비율이 높은 습관이 있으면 졸업 후보 카드가 표시됩니다. '졸업하기' 버튼을 선택하면 해당 습관이 완료 처리되고, 이후 새로운 습관을 추가할 수 있습니다.

### 6.4 리포트 평가

리포트 하단의 평가 버튼을 선택하여 해당 리포트의 유용성을 평가합니다. 평가 결과는 다음 리포트 생성 시 AI의 서술 방향에 반영됩니다.

### 6.5 리포트 삭제

리포트 카드를 길게 누르면 삭제 확인 메시지가 나타납니다. 삭제를 확인하면 해당 리포트가 제거됩니다.

## 7. 마이페이지

하단 내비게이션 바 우측의 마이페이지 아이콘을 선택하면 개인 설정 화면으로 이동합니다.

- **테마 변경**: 서비스 전체에 적용되는 색상 테마를 변경합니다.
- **성격 재테스트**: 시간이 지나 성향이 변화했다고 느껴질 때 성격 유형 테스트를 다시 진행하여 습관 추천의 기반 데이터를 업데이트합니다.
- **계정 정보 확인**: 가입 이메일 및 닉네임을 확인합니다.
- **로그아웃**: 현재 계정에서 로그아웃합니다.
- **회원 탈퇴**: 계정을 영구 삭제합니다. 탈퇴 시 저장된 습관, 일기, 리포트 등 모든 개인 데이터가 삭제되며 복구할 수 없습니다.

## 8. 자주 묻는 질문

**Q. 리포트가 자동으로 생성되지 않습니다.**  
자동 생성은 주간 리포트의 경우 매주 일요일 오후 10시, 월간 리포트의 경우 매월 말일 오후 10시에 서버에서 처리됩니다. 해당 시간이 지났는데도 리포트가 보이지 않는 경우 리포트 화면의 '리포트 생성' 버튼을 선택하여 수동으로 생성할 수 있습니다.

**Q. 인터넷 연결이 없어도 앱을 사용할 수 있나요?**  
습관 체크, 일기 작성 등 기본 기능은 오프라인 상태에서도 사용할 수 있습니다. 입력한 데이터는 기기에 즉시 저장되며, 인터넷 연결이 복구되면 최대 5초 이내에 자동으로 서버에 동기화됩니다. 단, AI 리포트 생성은 인터넷 연결이 필요합니다.

**Q. 비밀번호 재설정 이메일이 오지 않습니다.**  
스팸 메일함을 먼저 확인합니다. 스팸 메일함에도 없는 경우 몇 분 후 다시 시도합니다. 가입 시 사용한 이메일 주소를 정확히 입력했는지 확인합니다.

**Q. 일기를 삭제하면 리포트에도 영향이 있나요?**  
삭제된 일기는 이후 생성되는 리포트의 감정 분석에서 제외됩니다. 이미 생성된 리포트의 내용은 변경되지 않습니다.

**Q. 같은 날 일기를 두 번 작성할 수 있나요?**  
하루에 하나의 일기만 작성할 수 있습니다. 이미 작성한 날의 일기 화면에 다시 진입하면 기존 내용을 불러와 수정할 수 있습니다.

**Q. 온보딩에서 설정한 습관을 나중에 바꿀 수 있나요?**  
홈 화면에서 언제든지 습관을 추가, 수정, 삭제할 수 있습니다. 마이페이지의 '성격 재테스트' 기능을 이용하면 성격 유형을 다시 분석하여 새로운 맞춤 추천을 받을 수도 있습니다.

**Q. 리포트 분석에 최소 몇 건의 데이터가 필요한가요?**  
습관 이행 데이터가 전혀 없어도 리포트는 생성됩니다. 단, 감정 일기가 충분히 쌓일수록 분석의 정확도가 높아집니다. 시계열 인사이트는 같은 기간 유형의 리포트가 2개 이상 누적된 경우에 제공됩니다.

## 9. 데이터 이용 안내

HABITS는 서비스 제공을 위해 다음과 같은 데이터를 수집하고 활용합니다.

| 수집 데이터 | 활용 목적 |
|---|---|
| 이메일 주소 | 계정 인증, 비밀번호 재설정 |
| 닉네임 | 서비스 내 표시 |
| 성격 테스트 결과 | 습관 추천 방향 설정 |
| 주간 일정 | 습관 시간대 배정 |
| 습관 이행 기록 | 이행률 집계, 리포트 생성, 졸업 판정 |
| 감정 일기 텍스트 | KoELECTRA 기반 감정 분석, 리포트 생성 |
| 기분 점수 및 감정 태그 | 감정 트렌드 분석, 리포트 생성 |

수집된 데이터는 서비스 내 분석 목적으로만 활용되며, 사용자 동의 없이 제3자에게 제공되지 않습니다. 마이페이지의 '회원 탈퇴' 기능을 통해 계정을 삭제하면 저장된 모든 개인 데이터가 즉시 삭제됩니다.

본 서비스는 정신건강 치료나 의학적 진단을 제공하지 않습니다. 심리적 어려움이 지속되는 경우 전문 상담사 또는 의료 전문가에게 도움을 요청하시기 바랍니다.
